# 一隅 Focus

一个温和的个人专注空间。Windows 与安卓共用专注逻辑、记录格式和界面图标，记录可通过自己的坚果云账号同步。

## 下载安装

普通用户请到 [最新版本下载页](https://github.com/QiWeiYouWei/yiyu-focus/releases/latest)。在 Assets（资源）中下载 Windows 的 `.exe` 或安卓的 `.apk`；“Code → Download ZIP”是源码。

[Windows 0.12.0 下载](https://github.com/QiWeiYouWei/yiyu-focus/releases/download/v0.12.0/Yiyu-Focus-0.12.0-Windows.exe) · [安卓 0.12.0 下载](https://github.com/QiWeiYouWei/yiyu-focus/releases/download/v0.12.0/Yiyu-Focus-0.12.0-Android.apk)

## 直接使用

打开 `release/Yiyu-Focus-0.12.0-Windows.exe`。这是便携启动程序，不需要安装 Node.js。数据仍存放在 Windows 用户目录，移动 EXE 不会带走记录。也可以运行 `release/win-unpacked/Yiyu Focus.exe`，但需要保留同目录全部文件。新版沿用原数据目录，升级保留旧版记录与账号连接。

安卓安装包：`release/Yiyu-Focus-0.12.0-Android.apk`，支持 Android 8.0 及以上。在手机安装后，使用 Windows 端相同的坚果云邮箱和应用密码连接同步。详见 [安卓使用与开发说明](./android/README.md)。

安卓沿用叶子图标、卡片与动效，包含专注/休息、分心暂存、课程学习习惯、热力图、学习回顾、未解决问题、回收站、自动备份与 JSON 导入导出。切到学习资料或锁屏后计时继续；到点柔和提醒，返回后选择续读或结束。首次使用可在偏好设置开启通知和准时提醒权限。

## 记录口径与保护

- 0.5.0 兼容旧记录和旧备份，未标课程的记录归入“未分类”，可在学习足迹或当天详情中补充课程。课程学习习惯、收获、疑问及解决状态、下一步和专注时暂存的念头随账号同步；正在输入但尚未开始的目标草稿和计时只保存于当前设备；自动备份、回收站和桌面快捷键设置也仅留在本机。同步的本机资料路径在另一台设备可能需要重新选择。
- 新增课程学习习惯同步数据，所有连接同一账号的 Windows 客户端请一起升级到 0.5.0；旧版客户端无法读取含新课程习惯的同步文件。
- 周回顾取今天及之前 6 个本地自然日，不按星期一重置。只有从“我分心了”在专注时保存的念头进入分心汇总，相同文字（忽略多余空格和大小写）合并计数；旧版来源不明的念头仍在暂存箱保留。
- 没有预填、示例或伪造的专注记录。任务是持久待办，不会在午夜自动清空。
- 有效时长不包含暂停；每日至少累计 1 分钟才计为连续专注日。当日尚未达标时，连续天数允许接续昨天。
- 跨午夜的单次专注全部计入结束当天；休息时间不进入专注统计。
- Windows 正常关闭、锁屏或系统休眠会暂停；重开后手动继续。应用异常终止时，恢复最近 5 秒检查点，最多损失约 5 秒计时，不把关闭期间误算为学习。
- 安卓记录与加密授权存放在应用私有目录，卸载会删除本机记录。请先同步或导出；手机重启会暂停当前计时，系统强制停止应用可能使后台提醒失效，部分手机也会限制后台提醒。安卓计时不跨设备同步，学习资料的本机文件需在手机重新选择。
- Windows 数据通常位于 `%APPDATA%/yiyu-focus/focus-data.json`，通过临时文件替换写入。读取失败时保护原文件，不自动覆盖。
- 默认离线保存、无埋点。连接自己的坚果云账号并确认后，任务、专注记录、念头及偏好通过 HTTPS 同步到自己的网盘。未连接时不上传。请定期导出；导入会替换当前数据，并先验证格式与确认，桌面版恢复前会自动保护原文件；连接同步时这些修改也会上传。
- Windows 系统的勿扰/通知设置可能抑制系统通知；应用内仍会显示收尾选项。
- 针对本机 Electron GPU 启动异常，Windows 版默认关闭硬件加速，采用软件渲染；不关闭渲染器沙盒。启动与进程异常写入数据目录的 `startup.log`，不记录学习内容。
- 本版本使用温和引导，不拦截网站或软件，也不声称能自动检测实际注意力。

## 开发与验证

需要 Node.js 与 npm。依赖版本记录在 `package-lock.json`。

```powershell
npm ci
npm start       # Windows 桌面开发
npm run dev    # http://127.0.0.1:4173
npm test       # 计时、日期、连续天数、导入验证和成长数据汇总
npm run test:growth # 成长图表交互、筛选、缺失值和五种屏幕尺寸
npm run test:learning-ui # 新功能完整流程、旧记录与备份兼容
npm run test:workflow-ui # 续读、课程习惯、问题筛选、三类回收恢复
npm run test:floating # 原生小窗、快捷暂存、受保护恢复与偏好重启
npm run test:ui # 使用已安装的 Microsoft Edge 做 UI 集成测试
npm run test:desktop # 使用隔离数据目录测试 Electron 保存与重启
npm run test:sync-ui # 用模拟 WebDAV 测试真实桌面凭证加密、合并与断网重试
npm run dist   # 构建 Windows x64 便携版
node tests/portable.cjs # 验证最终 EXE 解压、启动、保存与退出
```

构建时如 Electron 下载超时，但本机 `npm start` 已可运行，可使用 `npm run dist -- --config.electronDist=node_modules/electron/dist` 复用已安装的同版本运行组件。

UI 测试使用独立浏览器上下文，不写入真实用户数据。桌面测试通过 `YIYU_FOCUS_DATA_DIR` 指定隔离目录。测试截图在 `test-results/`。

## 跨平台架构

- `web/core.mjs`：不依赖平台的计时、统计和备份验证。
- `web/learning.mjs`：下一步恢复、课程聚合和近七天回顾，可复用到安卓端。
- `web/workflow.mjs`：柔和计时收尾、课程习惯、回收与恢复。
- `desktop/floating.cjs` / `web/mini.*`：独立小窗与受限制的快捷操作；Windows 焦点辅助进程仅查询/恢复前台窗口句柄，不读取其他窗口内容。
- `desktop/data-store.cjs`：串行原子保存、轮转备份和受保护恢复。
- `web/app.mjs`：页面与状态管理；桌面通过窄接口 IPC 读写，网页通过 localStorage 保存。
- `web/index.html` / `style.css` / `polish.css` / `ui.mjs`：响应式界面，可复用到移动端。
- `desktop/`：Electron 桌面外壳，隔离上下文与沙盒开启，禁用任意窗口和页面跳转。
- `web/sync.mjs`：跨端记录合并、删除标记和本地同步索引。
- `desktop/webdav.cjs` / `sync-service.cjs`：固定坚果云端点、条件写入、版本缓存和 Windows 加密凭证存储。每台设备一个独立文件，避免同时覆盖共享快照。

- `android/`：Java 原生外壳与受限 WebView，本地打包全部界面资源；Android Keystore 加密授权，原子存储和备份、原生 WebDAV、系统文件选择、后台到点通知与返回键适配。
- `web/android.mjs`：仅在安卓启用的窄接口适配，复用共享的完整数据校验与同步合并。

账号同步使用坚果云账号授权，未建立独立的“一隅”注册体系。应用离线也能使用，安卓不依赖 GPT 站点或 Google 服务。安卓已在专用 Android 15 模拟器验证，仍需在自己的手机检查厂商后台限制、字体显示和资料打开行为。

参考：[Electron 安全指南](https://www.electronjs.org/docs/latest/tutorial/security)、[Android WebView 安全与本地资源](https://developer.android.com/develop/ui/views/layout/webapps/load-local-content)。
