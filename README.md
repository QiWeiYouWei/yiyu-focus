# 一隅 Focus

一个温和的个人专注空间。Windows 桌面版优先，界面与专注逻辑独立于桌面容器，后续可用于安卓客户端。

## 直接使用

打开 `release/Yiyu-Focus-0.3.0-Windows.exe`。这是便携启动程序，不需要安装 Node.js。数据仍存放在 Windows 用户目录，移动 EXE 不会带走记录。也可以运行 `release/win-unpacked/Yiyu Focus.exe`，但需要保留同目录全部文件。新版沿用原数据目录，升级保留旧版记录与账号连接。

0.3.0 优化卡片、字体层次与统一图标，增加页面过渡、专注呼吸光晕、完成反馈和同步状态动画。「偏好设置 → 轻柔动效」可关闭动画，同时遵循系统的减少动画设置；动效偏好仅保存在当前设备。

0.2.0 新增坚果云个人免费版账号授权同步。点击右上角「账号同步」，按 [账号同步开通说明](./账号同步开通说明.md) 设置。无需开通付费云服务器。

1. 写下一个具体的小目标，选择 5 / 15 / 25 / 45 分钟或自定义 1–120 分钟。
2. 开始专注，分心时点击“我分心了”，把念头暂存。计时会继续。
3. 完成后留下收获，进入短暂休息；提前结束也保留实际专注时长。
4. 在“我的成长”查看累计时间、单日最高、最长单次、当前和最长连续天数、全年热力图及近七天统计。
5. “偏好设置”中修改昵称、签名、每日目标、默认时长、休息时长；导出或恢复 JSON 备份。

支持独立窗口、置顶、沉浸模式、提示音和 Windows 完成通知。未聚焦按钮或输入框时，空格开始/暂停；Esc 退出沉浸模式。

## 记录口径与保护

- 没有预填、示例或伪造的专注记录。任务是持久待办，不会在午夜自动清空。
- 有效时长不包含暂停；每日至少累计 1 分钟才计为连续专注日。当日尚未达标时，连续天数允许接续昨天。
- 跨午夜的单次专注全部计入结束当天；休息时间不进入专注统计。
- 正常关闭、锁屏或系统休眠会暂停；重开后手动继续。应用异常终止时，恢复最近 5 秒检查点，最多损失约 5 秒计时，不把关闭期间误算为学习。
- Windows 数据通常位于 `%APPDATA%/yiyu-focus/focus-data.json`，通过临时文件替换写入。读取失败时保护原文件，不自动覆盖。
- 默认离线保存、无埋点。连接自己的坚果云账号并确认后，任务、专注记录、念头及偏好通过 HTTPS 同步到自己的网盘。未连接时不上传。请定期导出；导入会替换当前数据，并先验证格式与确认，连接同步时这些修改也会上传。
- Windows 系统的勿扰/通知设置可能抑制系统通知；应用内仍会显示结束复盘。
- 针对本机 Electron GPU 启动异常，Windows 版默认关闭硬件加速，采用软件渲染；不关闭渲染器沙盒。启动与进程异常写入数据目录的 `startup.log`，不记录学习内容。
- 本版本使用温和引导，不拦截网站或软件，也不声称能自动检测实际注意力。

## 开发与验证

需要 Node.js 与 npm。依赖版本记录在 `package-lock.json`。

```powershell
npm ci
npm start       # Windows 桌面开发
npm run dev    # http://127.0.0.1:4173
npm test       # 计时、日期、连续天数、导入验证
npm run test:ui # 使用已安装的 Microsoft Edge 做 UI 集成测试
npm run test:desktop # 使用隔离数据目录测试 Electron 保存与重启
npm run test:sync-ui # 用模拟 WebDAV 测试真实桌面凭证加密、合并与断网重试
npm run dist   # 构建 Windows x64 便携版
```

UI 测试使用独立浏览器上下文，不写入真实用户数据。桌面测试通过 `YIYU_FOCUS_DATA_DIR` 指定隔离目录。测试截图在 `test-results/`。

## 架构与安卓后续

- `web/core.mjs`：不依赖平台的计时、统计和备份验证。
- `web/app.mjs`：页面与状态管理；桌面通过窄接口 IPC 读写，网页通过 localStorage 保存。
- `web/index.html` / `style.css` / `polish.css` / `ui.mjs`：响应式界面，可复用到移动端。
- `desktop/`：Electron 桌面外壳，隔离上下文与沙盒开启，禁用任意窗口和页面跳转。
- `web/sync.mjs`：跨端记录合并、删除标记和本地同步索引。
- `desktop/webdav.cjs` / `sync-service.cjs`：固定坚果云端点、条件写入、版本缓存和 Windows 加密凭证存储。每台设备一个独立文件，避免同时覆盖共享快照。

安卓尚未构建 APK。下一阶段可以把 `web/` 放入 Capacitor 容器，接入原生存储、后台计时和通知、生命周期暂停恢复、系统返回键与安全区，最后在真机验证。网页的响应式适配不等于安卓后台功能已经完成。账号同步目前使用坚果云账号授权，未建立独立的“一隅”注册体系；安卓需要补齐 WebDAV 原生网络接口与安全凭证存储。

参考：[Electron 安全指南](https://www.electronjs.org/docs/latest/tutorial/security)、[Capacitor 文档](https://capacitorjs.com/docs)。
