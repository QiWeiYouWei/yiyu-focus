# Luna 素材

由用户提供的 Luna-v2 透明精灵图，用于一隅 Windows 桌宠。复制后与原图的 SHA-256 一致，未重绘、裁改或覆盖原素材，也未修改 Codex 安装或宠物配置。

`manifest.json` 记录尺寸、状态行和原图摘要。完整图为 1536×2288，8 列、11 行，单帧 192×208。运行时按状态读取帧，平滑绘制并适配屏幕缩放。

原有第 7 行工作动作用于专注，第 3 / 4 行挥手和跳跃用于结束反馈，第 0 行第 1 帧闭眼姿势用于休息。保留所有原始动作和注视帧，未生成新的学习或睡眠画面。

0.17.0 用原有第 6 行回应摸头，第 5 行回应“我有点累”，第 3 行微笑挥手回应鼓励与焦虑。互动约 2.4 秒后恢复当前计时动作，关闭动效时显示静态姿势。原图保持不变。

0.18.0 使用原有第 9 / 10 行共 16 个注视帧：从正上方起，按顺时针排列。桌面光标位置来自 Electron 原生屏幕 API，按眼部附近的屏幕坐标计算方向；文字、工作、休息与互动状态仍由真实计时和主动操作决定。
