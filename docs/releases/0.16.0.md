# 一隅 Focus 0.16.0 · 课程外观与优先级

Windows 便携版：`release/Yiyu-Focus-0.16.0-Windows.exe`。

## 给课程设置图标或封面

在“课程追赶”中点击“添加课程”或“编辑课程”。

- 默认按课程名称匹配电子、信号、数学、物理等图标，匹配不到时使用阅读图标。旧课程无需重新录入。
- 展开“选择课程图标”，可以选阅读、电子、信号、数学、物理、实验、编程、语言、地理、艺术，或选“自动”。
- 点击“上传 / 替换封面”，选择本机 JPG、PNG 或 WebP 图片，在编辑页预览后保存。支持不超过 12 MB 的原图；图片居中裁成横向封面并压缩，保存后不依赖原图片文件。
- 图标和封面可以同时使用；移除封面后，课程仍显示图标。上传、替换、移除都在点击“保存课程”后生效，取消编辑会保留原设置。
- 未能读取的图片会提示原因并保留当前封面。封面准备期间暂停保存，避免保存到尚未完成的图片。

## 自己区分重要和紧急

编辑页分别设置两项：

| 设置 | 可选程度 | 含义 |
| --- | --- | --- |
| 重要程度 | 常规、重要、非常重要 | 这门课对你有多关键 |
| 紧急程度 | 不紧急、较紧急、很紧急 | 你希望多快处理 |

课程卡片和今日追赶任务都显示这两个标记。旧课程默认按常规、不紧急处理，不根据缺口大小擅自修改你设置的程度。

课程列表新增“按优先级 / 按课程名称 / 按添加顺序”三种排列方式，重开后保留。优先级排列与今日任务采用同一规则：

1. 第一个待补知识点已过期或今天截止时优先。
2. 比较紧急程度。知识点将在 3 天内截止时，计算时至少按很紧急；7 天内截止时，至少按较紧急。这不修改你保存的手动标记。
3. 同样紧急时，比较重要程度，再比较截止日期。
4. 今日任务仍以每门课的第一个未掌握知识点为起点，并遵守当前学期范围和每日时间预算；条件相同时参考估计剩余时间。

修改图标、封面或优先级，不改变学校位置、知识点标识、掌握程度或已有专注关联。

## 保存与升级

沿用原本的数据目录和备份方式。图标、封面、重要和紧急程度、排列方式都包含在 JSON 备份里，关闭后重开或从备份恢复仍可使用。

课程目录、学期和封面仍在本机保存，本轮未加入账号同步，未更新安卓安装包。

## 验证

`npm test` 检查旧数据兼容、图片字段校验、手动优先级排序、截止日期优先和备份保留。

`npm run test:courses` 用隔离浏览器检查图标选择、图片解码压缩、实际显示、替换、移除、取消、错误文件、重要和紧急标记、排列方式、学期范围、重开、备份导入导出与窄屏布局，并回归原有课程与学期流程。

设置 `YIYU_COURSES_PACKAGED=1` 后运行 `node tests/courses-ui.cjs`，验证实际 EXE。测试图片和课程进度只使用隔离数据，不写入个人记录。
