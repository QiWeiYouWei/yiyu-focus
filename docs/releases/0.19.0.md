# 一隅 Focus 0.19.0

安卓与 Windows 更新为同一版本，继续保留叶子图标。

- 安卓增加课程追赶、知识点与学校进度确认、自定义学期、课程图标、本机封面和重要 / 紧急程度。
- 安卓课程封面使用系统图片选择器，只允许 JPG、PNG、WebP；图片居中裁切、压缩后随本机记录和 JSON 备份保存。
- 安卓移除桌宠交互入口，安装包不含桌宠素材、不请求桌面悬浮权限。Windows 保留 Luna 的专注／休息／完成联动、温柔互动、问候告别和光标注视。
- 修复移动项目到中文路径后的安卓构建检查。

## 保存与升级

课程追赶目录、学期、封面、掌握程度和排序仍只在本机保存，可通过 JSON 导出、导入转移，尚未加入坚果云同步。原有专注记录、日历、常用专注和跨设备接力继续沿用同一坚果云账号。

安卓沿用原应用 ID 和发布签名，直接覆盖安装即可，勿先卸载。Windows 数据目录沿用，移动 EXE 不影响本机记录。

在 GitHub Release 的 Assets 中下载 Windows EXE 或 Android APK。源码下载 ZIP 不能直接安装。

## 验证

88 项共享逻辑测试及 5 项发布保护测试通过。共享页面与最终 Windows EXE 验证课程、学期、封面、优先级与本机保存；安卓实际 WebView 验证系统图片选择、课程掌握记录、JSON 导出导入和无桌宠入口，原有后台计时、进程回收通知、收尾与备份流程通过。正式 APK 经签名校验、Lint 与安装启动检查。手机和平板布局使用模拟器和 360 / 412 / 800 像素宽度验证，未在真实三星设备上测试。
