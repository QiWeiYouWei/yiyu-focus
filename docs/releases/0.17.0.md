# 一隅 Focus 0.17.0 · Luna 温柔陪伴

Windows 便携版：`release/Yiyu-Focus-0.17.0-Windows.exe`。沿用已有学习记录与桌宠位置，旧版桌宠偏好默认使用“温柔鼓励”。

## 和 Luna 互动

- 点 Luna 的头：获得一句小回应和亲近动作；重复互动会轮换文字。
- 点她上方的“Luna · 聊聊”：选择“给我一点鼓励”“我有点累”“进度落后，有点焦虑”。她会分别肯定积累、提醒照顾自己、引导把任务缩成一个知识点。
- 聊聊不改变你的计时，不自动开始、暂停或替你决定休息。想调整计时，可点左上角箭头回到一隅。
- 拖动身体或文字气泡调整位置；头部是互动区域。鼠标穿透开启时须先在偏好关闭穿透，才能操作桌宠。

## 根据真实学习回应

开始时提到正在学的课程，暂停和继续时给予温和反馈，分心念头成功暂存后鼓励回来。结束时引用本段真实投入：提前结束也承认付出的时间；完成后挥手跳跃。主动请求鼓励时，可引用今天已记录的时长和已有连续天数，不把计时推断为知识掌握程度。

回应采用本机文案，不需要联网或 AI 账号，不上传情绪选择、课程名称或学习记录。Luna 没有开放式聊天功能。情绪由你主动选择，不读取其他窗口或推测你的状态。

## 陪伴方式由你决定

在“偏好 → Luna · 陪你专注”选择：

- **温柔鼓励**：只在开始、暂停、回来、结束等关键时刻回应，普通计时更新不会重复刷文字。自动文字约 11 秒后回到简短状态，快速操作会抑制连续自动鼓励。
- **安静陪伴**：保留计时状态与学习动作，关闭自动长句和结束庆祝；摸头或聊聊时仍会回应。主动互动的文字约 14 秒后恢复状态。

动画沿用原素材。亲近、困倦、微笑挥手约 2.4 秒后恢复当前动作，界面关闭动效或系统减少动画时使用静态姿势。窗口仍透明、置顶、不抢焦点，可最小化主窗口后继续陪伴。

陪伴方式、大小、鼠标穿透和位置只保存在本机 `pet-preferences.json`，不属于学习 JSON 备份或账号同步。安卓本轮仍为 0.12.0。

## 验证

`npm test` 检查真实时长文案、课程上下文、冷却与去重、回复过期、安静模式和静态动作。

`npm run test:pet` 使用隔离数据验证真实桌面互动、最小尺寸、分心回应、计时稳定、旧设置兼容、拒绝无效设置、尺寸与位置保存、鼠标穿透、动效关闭、主窗口最小化及退出清理。

`node tests/luna-portable.cjs` 启动实际便携 EXE，验证互动、课程上下文、计时兼容、安静模式及重开保存。测试不改动个人学习数据。
