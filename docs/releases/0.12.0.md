# 一隅 Focus 0.12.0

这次把专注界面、重复安排、记录修正和跨设备接力一起补齐。Windows 与安卓共用界面、图标和数据规则；安卓小组件本轮不加入。

- **沉浸专注**：当前目标、课程和学习位置与计时一起显示，隐藏时长选项和侧栏。可以在偏好中开启“开始专注时自动进入沉浸界面”，随时退出，计时与暂存念头保留。
- **重复安排**：每天、工作日或每周指定日期，选择结束日期（最多一年）。每次安排可独立完成、专注和提醒；修改和删除可以选择“仅这一次”或“这次及后续”，之前的安排保留。被删除的实例可在回收站逐项恢复。
- **补记与修正**：“学习足迹 → 补记专注”填写过去的结束时间、时长、课程和收获；记录可“修正时长”，保留最初时长和已有学习量、问题、事件关联。补记标明来源，最多 120 分钟，不触发庆祝。
- **准确跨日统计**：新版计时保存实际专注区间，暂停和到点等待不累计；跨午夜分别计入当天，热力图、趋势、课程近七天统计与周回顾使用同一规则。旧计时缺少完整区间，保留原有结束日统计；手动修正按结束时间向前连续分配时长，不会推算过去的暂停过程。
- **跨设备接着学**：两台设备连接同一坚果云账号。源设备点“暂停并发送接力”，另一台点“刷新接力 → 接手这一段”，确认保存后点击继续。保留目标、已专注时长、课程、学习位置、学习量和事件关联，最后只产生一段记录。原设备在交接期间不能继续或结束，可刷新或撤回；接力需要联网，普通离线专注不受影响。
- **可选完成反馈**：达到每日目标、连续天数或累计时长里程碑时，轻微叶子动效或彩纸礼炮，也可关闭。已记录的同一里程碑只提示一次，补记和云端合并不触发，遵循系统减少动画设置。

## 使用与升级

请把 Windows 与安卓都升级到 0.12.0。新版本保留原数据目录与账号连接，安卓沿用原签名，可覆盖安装。界面偏好、反馈记录与接力确认凭据仅保存在当前设备；完成记录、补记、修正和具体日历实例沿用账号同步。旧客户端不能发起接力，且不会正确显示新的跨日分配，升级后再一起使用。

接力使用坚果云 YiyuFocus/handoff.json，独立于普通记录同步。条件写入防止两台同时接手；网络回复不确定时源设备保持暂停，刷新或确认撤回后再继续。接手后本机保存失败可在同一接手设备刷新恢复；双方确认本机保存前保留交接凭据。源设备最迟在手动刷新或约一分钟检查后清除已经被接手的计时。

每次重复安排是独立实例，按当前本地日期生成到指定结束日，不会无限延展。提醒仍需 Windows 应用保持运行，安卓需通知及准时提醒权限，厂商后台限制可能影响提醒。
