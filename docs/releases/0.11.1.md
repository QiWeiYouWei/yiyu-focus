# 一隅 Focus 0.11.1

本次更新调整热力图的时间梯度，并增加快速专注图标。

- 热力图按每天累计的专注时间分档：未专注、不足 1 小时、1–不足 2 小时、2–不足 3 小时、3–不足 4 小时、4 小时及以上。每满一小时加深一档，4 小时及以上才显示最深绿色；历史记录自动按新规则显示。
- 快速专注图标从 12 个增加到 36 个，包含阅读、单词、听力、口语、数学、编程、电路、科学、绘画、乐器、运动、冥想等。手机上的图标面板可滚动，保留至少 44px 的点击范围。
- Windows 与安卓采用相同界面和分档规则。安卓沿用原发布签名，版本号 0.11.1，支持覆盖升级；已有记录和账号连接继续保留。

## 下载

在下方 Assets 中选择：

- `Yiyu-Focus-0.11.1-Windows.exe`：Windows 便携版，下载后双击运行。
- `Yiyu-Focus-0.11.1-Android.apk`：安卓安装包，可覆盖升级。
- `Yiyu-Focus-0.11.1-SHA256.txt`：安装包 SHA256 校验值。
