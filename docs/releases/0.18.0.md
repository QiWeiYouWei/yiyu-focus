# 一隅 Focus 0.18.0 · 光标注视

Windows 便携版：`release/Yiyu-Focus-0.18.0-Windows.exe`。升级沿用原记录、桌宠位置和陪伴偏好。光标注视默认开启。

## 开关与使用

- Luna 上方的**眼睛按钮**可直接开关注视，紫色为开启，灰色为关闭；悬停可查看当前状态。
- “偏好 → Luna”里也有“光标注视”复选框，保存后立即生效。两处开关保持一致，关闭后重开应用仍保留。
- 待机时，Luna 使用原素材里的 16 个方向望向桌面鼠标，保留自然眨眼；光标靠近头部时回到自然待机，方向边界带少量缓冲，避免抖动。
- 学习和等待收尾时，鼠标移动会让她短暂抬眼；停止移动约 1.4 秒后继续原来的工作或等待动作。
- 摸头、困倦、挥手、庆祝、问候、告别等动作优先显示；暂停与休息时保持闭眼静待。

这是 Windows 桌宠的全局光标跟随。鼠标移出桌宠窗口、主应用最小化或开启鼠标穿透后仍能注视。开启穿透时，桌宠按钮不能点击，可在主应用偏好中调整开关，或先关闭穿透。

关闭界面动效或系统减少动画时暂停注视，保留开关选择。安静陪伴仍可跟随光标。桌宠隐藏、关闭注视、休息、暂停及退出时停止相应采样。

实时坐标仅在本机用于显示方向，设置保存于 `pet-preferences.json`；学习 JSON 备份和账号同步沿用原规则。原素材保持不变，安卓本轮仍为 0.12.0。

## 验证

`npm test` 验证 16 个方向、负坐标、头部附近区域、方向缓冲、动作优先级、静态模式、学习后恢复工作，以及采样在隐藏或关闭时停止、静止光标不续期。

`npm run test:gaze` 使用隔离数据和真实 Windows 光标验证四个主方向、窗口外跟随、主窗口最小化、穿透、桌宠与主界面开关、学习中抬眼后回到工作、暂停闭眼、小尺寸布局、减少动画、旧偏好默认值、无效值拒绝与重开保存。测试结束恢复原光标位置。

原有 `npm run test:pet` 与 `npm run test:luna-lifecycle` 回归互动、问候告别、计时保存和退出清理。`node tests/luna-portable.cjs` 验证实际便携 EXE 的光标注视、互动和偏好保存。
