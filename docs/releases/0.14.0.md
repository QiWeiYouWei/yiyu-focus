# 一隅 Focus 0.14.0 · 课程追赶

本地 Windows 便携版：`release/Yiyu-Focus-0.14.0-Windows.exe`。

## 第一次使用

1. 打开侧栏“课程追赶”，或专注首页下方的课程入口。
2. 已为本次使用准备“模拟电子技术基础”和“信号与系统”两个空目录。点击“添加知识点与资料位置”，从你的教材、PPT 或平台课程列表粘贴目录。学校位置和掌握程度没有预填。
3. 每行一个知识点，只写名称也能保存。完整格式为：`知识点 | 教材位置 | PPT 位置 | 平台课次 | 预计分钟 | 截止日期 | 下一步`。空列保留竖线，日期使用 `YYYY-MM-DD`，预计时长为 5–480 分钟的整数；默认 25 分钟。
4. 点击“更新学校进度”，选择老师已经讲完的最后一个知识点，填写来源说明。支持教材章节、PPT 页码与课程平台；可记录 http/https 网页地址。这里保存来源，不自动登录平台或解析教材文件。
5. 展开知识点，按实际情况选择“尚未学习 / 看过，仍需理解 / 能跟着例题做 / 能独立做题”。可以独立更新任何一项；不把最靠后的一个已掌握知识点当成前面全部学会。
6. 设置每日追赶预算，点“先做 5 分钟”开始。专注结束时，可以确认该知识点的掌握程度；留空会保留原值。点击“回到空间”也会保存已填写的掌握程度。

## 进度与建议怎么算

- 只统计已确认学校范围内、尚不能独立做题的知识点。学校位置不确定时不显示推测的落后量。
- 分别显示学校已讲、我已学过、能独立做题的数量；比例按知识点计数，不代表学分或能力评分。
- 每门课只推荐第一个待补知识点，优先考虑该知识点的截止日期，再按剩余估计时间排序。目录顺序作为学习顺序，不自动推断课程依赖。
- 本轮每门课安排最多 25 分钟；预算不足 5 分钟时不安排新任务。点击开始统一以 5 分钟降低启动门槛，之后可使用已有的续读功能。
- 估计剩余时间来自你填写的初始时间：未学按 100%、看过按 80%、跟着例题做按 45%、独立做题按 0%。这是启发式估计，尚未根据历史速度自动训练或预测追平日期。
- 今日已投入仅汇总带有课程追赶关联的实际专注记录，并按实际区间分配到本地自然日。专注时间不自动换算成掌握程度。
- 学校确认超过 7 天会提示校准。修改知识点的数量或顺序后，学校位置重置为未确认；保留名称相同知识点的标识与掌握程度。

## 保存范围

- 沿用原有本地数据文件和自动备份。课程目录、来源、学校位置、掌握程度和追赶预算包含在 JSON 导出/恢复中。
- 本版课程目录和预算仅在本机保存，尚未加入账号同步。账号合并不会清空本机课程目录；专注记录沿用既有同步功能。
- 移除课程或删除/改名知识点前会确认；课程目录尚未加入回收站。已有专注记录仍保留，建议修改目录前导出备份。
- 本轮交付 Windows 版。安卓安装包没有在本轮更新。

## 开发验证

`npm test` 验证核心计算、兼容旧备份与数据保存。`npm run test:courses` 验证真实页面录入、学校来源确认、预算、关联专注与掌握更新、重开、备份导入导出、目录变更、文本转义和窄屏布局。

设置 `YIYU_COURSES_PACKAGED=1` 后运行 `node tests/courses-ui.cjs`，用独立临时数据目录验证打包后的实际 EXE。测试中的章节与进度为测试材料，不写入个人数据。
