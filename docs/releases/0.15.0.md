# 一隅 Focus 0.15.0 · 课程与学期

Windows 便携版：`release/Yiyu-Focus-0.15.0-Windows.exe`。

## 自己添加课程

打开“课程追赶”，点击右上角“添加课程”，填写课程名称、所属学期和知识点目录，保存即可。知识点可以暂时留空，后续点“编辑课程”再补齐。目录输入方法沿用 [0.14.0 说明](./0.14.0.md)。

新增课程默认归入正在筛选的具体学期；查看全部或未分类时，默认使用当前学期。你可以自行改选“未分类”。添加课程时也可以点“新建 / 管理学期”；创建后自动选中这个学期，已填写的课程名称和目录保持原样。

同一学期禁止新增同名课程，不同学期可以有同名课程，各自的知识点、学校进度和掌握程度独立保存。

## 按学期整理

1. 点击“管理学期”，输入名称，例如“大二上”或“2026–2027 第一学期”，保存。
2. 勾选“设为当前学期”，或对已有学期点“设为当前”。今日追赶任务只推荐当前学期的课程。
3. 在“按学期查看”下拉框选择全部、未分类或某个学期。这里只切换课程列表，不改变今日任务所用的当前学期。每个选项显示课程数量。
4. 点课程的“编辑课程”修改所属学期。只修改归属时，学校位置、知识点标识、掌握程度和原有专注关联均保留。
5. 学期可以改名；删除分类前会确认，该分类的课程移到未分类，不删除课程或学习记录。若删掉当前学期，今日任务改用未分类课程。

今日追赶预算仍按当天全部课程追赶记录计算；切换学期不会重新获得一天的时间预算。成长与学习足迹保留原有按课程名称统计的方式。

## 升级与保存

旧版课程自动显示为“未分类”，不会推测它们属于哪个学期。首次建立学期后，你可以把原有两门课分进去。所有学期、课程归属、当前学期和筛选状态包含在 JSON 备份里，重开后保留。

课程目录和学期分类仍在本机保存，本轮未加入账号同步，也未更新安卓安装包。原有专注、复盘、备份和已连接账号的专注记录同步继续使用。

## 验证

`npm test` 验证旧数据兼容、学期关联、同名课隔离、当前学期推荐范围、删除分类的数据保留和备份校验。

`npm run test:courses` 检查真实界面添加课程、移动课程、学期创建/改名/删除、当前学期切换、重复名称提示、嵌套新建学期时草稿保留、重开、备份导入导出和窄屏布局。

设置 `YIYU_COURSES_PACKAGED=1` 后运行 `node tests/courses-ui.cjs`，对实际 EXE 使用隔离数据执行上述主要流程。测试课程和进度不会写入个人数据。
