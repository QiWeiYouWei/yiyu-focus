# 一隅 Focus 0.17.1 · 开始与告别

Windows 便携版：`release/Yiyu-Focus-0.17.1-Windows.exe`。沿用已有记录与 Luna 设置。

打开应用时，Luna 会挥手说一句欢迎鼓励，文字会轮换；有未完成的专注时，提醒你准备好后可以继续。欢迎约 11 秒后恢复简短状态，正常计时更新不会刷掉问候，主动开始学习或摸头可获得新的回应。

关闭主窗口时，先暂停当前计时、保存记录并备份，再隐藏主界面，由 Luna 短暂挥手告别，约 3 秒后自动退出。告别会按真实记录肯定今天的投入，或提醒当前这段已经暂停；尚未开始也给予温柔回应。告别期间不增加专注时长，不把当前专注自动标成完成。

想立即离开，可以点告别下方的“立即关闭”。即使平时开启鼠标穿透，该按钮在告别期间也能点击；下次打开仍沿用原来的穿透设置。重复关闭请求不会重复保存或产生多次告别。保存失败时保留主窗口并提示重试，不显示保存成功的告别。

“安静陪伴”、隐藏或关闭 Luna 时，略过问候与告别，并直接完成退出；关闭动效或系统减少动画时，使用静态挥手姿势。问候与告别仍是本机文字，无需联网。

`npm test` 验证文案依据、空记录、已暂停计时、冷却去重与静态动作。`node tests/luna-lifecycle.cjs` 使用独立数据验证问候、原生与界面关闭、先保存后告别、告别时间不计入学习、保存失败保留窗口、立即退出与安静模式。`node tests/luna-portable.cjs` 验证实际便携 EXE 的问候、告别、重开保存和退出清理；原有 `npm run test:pet` 继续回归桌宠互动与偏好。
