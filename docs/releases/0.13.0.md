# 一隅 Focus 0.13.0 · Windows Luna 桌宠

首次打开新版时，Luna 会出现在屏幕右下角。她使用用户提供的 Luna-v2 原始透明精灵图，随一隅运行，不依赖 Codex 或原素材文件夹。

| 一隅状态 | Luna 的表现 |
| --- | --- |
| 未开始专注 | 安静待机 |
| 正在专注 | 工作 / 思考动作，显示当前倒计时 |
| 暂停或电脑锁屏后 | 闭眼静待，由你恢复计时 |
| 到点等待读完一段、延长或结束 | 检查 / 等待收尾 |
| 确认结束一段已有专注时间的学习 | 挥手，然后欢呼跳跃，约 4 秒后回到当前状态 |
| 休息计时 | 闭眼休息；动效开启时有轻微呼吸 |

欢呼只在实际结束专注时触发。未满 1 秒的取消、编辑或补记旧记录、重新启动、休息结束不会触发；到点仍由你选择怎样收尾。立即开始下一段学习会结束上一段欢呼。

## 调整陪伴

- 主界面右上角的 **Luna** 可以开启或隐藏桌宠。
- **偏好设置 → Luna · 陪你专注** 可以保存开关、80% / 100% / 125% 大小和鼠标穿透。
- 关闭鼠标穿透时，拖动角色或文字气泡可以移动她。位置会自动保存，重启后恢复。
- 鼠标靠近时显示小工具栏：`↗` 返回一隅，`×` 隐藏桌宠。鼠标穿透开启后，请从一隅偏好设置调整或关闭穿透。
- **回到屏幕右下角** 可找回桌宠；移除显示器或改变屏幕配置时会将她约束到可见工作区。
- 一隅的 **界面动效** 或系统的 **减少动画** 关闭动画时，Luna 会改用对应状态的静态姿势。

桌宠保持置顶、不会单独占用任务栏或自动抢走学习窗口的输入焦点；最小化主界面后仍陪伴。退出一隅会关闭桌宠。开关、大小、位置和穿透偏好只保存在本机，不改变学习记录和账号同步格式。

本轮交付 Windows 0.13.0。安卓仍可使用 0.12.0，同步记录兼容；本轮未提供安卓桌宠或新版 APK。

此版本同时包含 Windows 图标修复：固定位置的多尺寸 ICO、显示窗口前设置任务栏信息，移动便携 EXE 后仍可读取图标。沿用旧数据目录与账号连接。

## 本地验证

`npm test` 包含计时、数据、同步和桌宠动作选择测试。`npm run test:pet` 使用独立测试目录，覆盖真实 Electron 窗口、专注 / 暂停 / 收尾 / 欢呼 / 休息、大小与位置保存、隐藏与重启、动效关闭和退出清理。可用 `YIYU_TEST_EXE` 指定打包后的内部 EXE。

`node tests/portable.cjs` 检查最终便携程序的实际启动、学习记录、日历、快速专注、悬浮窗和保存流程。
