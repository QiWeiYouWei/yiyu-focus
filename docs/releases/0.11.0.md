# 一隅 Focus 0.11.0

给重要的事，一点时间。Windows 与安卓共用记录、账号同步和叶子图标。

## 下载与使用

- **Windows x64**：下载 **Yiyu-Focus-0.11.0-Windows.exe**，双击运行，无需安装 Node.js。升级时先退出旧版，再打开新版；原有记录与账号连接保留。
- **安卓 8.0 及以上**：下载 **Yiyu-Focus-0.11.0-Android.apk** 并安装。沿用原签名，可以覆盖升级；不要先卸载，卸载会删除本机记录。
- **文件校验**：需要核对下载完整性时，可对照 **Yiyu-Focus-0.11.0-SHA256.txt**。

## 这版新增

- 我的成长：每日投入趋势、课程投入分布、目标与实际学习量、分心原因分布。统一近 7 / 30 / 90 天，支持课程和单位筛选、触摸滑块、键盘与数据表。
- 独立日历：事件图标、跨天安排、DDL、学习量目标和直接开始专注；记录关联安排，显示投入和下一步。
- 快速专注：保存常用事件、固定时长和学习量；置顶、排序、复制，Windows 快捷键与安卓桌面入口。
- 温和引导：暂存分心原因后回到原目标，保留课程学习位置；到点可续读、延长或结束。
- 日历提醒：按开始时间或 DDL 设置提前量，支持稍后提醒。Windows 需要应用保持运行；安卓需要允许通知与准时提醒，厂商后台限制仍可能影响送达。
- 同步改进：清楚显示保存、待同步与离线状态；保留冲突版本供选择。

## 数据与验证

默认本地保存。连接自己的坚果云账号后，按既有记录格式同步；未填写的学习量不算作零，分心图仅统计主动记录的原因。没有预填学习数据。

数据测试、成长图表交互与响应式检查通过。发布流程验证最终 Windows 程序；安卓使用本机已验证的原签名安装包，并在发布时校验字节和 SHA-256。安卓已做模拟器覆盖升级检查，尚未在三星手机和平板实机验证。
